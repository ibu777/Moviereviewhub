Movie Review App

A React + Vite app that fetches movie data from the OMDb API and lets users browse movies, view details, and save their own movie ratings in local storage.

Features

- Fetches movie data from OMDb
- Displays a movie list with title, year, genre, poster, and description
- Supports search by movie title
- Supports filtering by genre and year
- Shows a detailed movie view panel
- Allows users to rate movies from 1 to 5 stars
- Persists user ratings in browser local storage

Tech Stack

- React
- Vite
- Tailwind CSS


Notes

- The app uses the OMDb API with the public demo API key provided in the project.
- Ratings are stored locally in the browser using local storage.
